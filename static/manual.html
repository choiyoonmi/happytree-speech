1로그인

주소는 happytree-speech.onrender.com 하나입니다. 선생님·학생 모두 같은 주소로 들어가요.

선생님(관리자)

  1. 주소 접속 → 상단에서 선생님 선택
  2. 관리자 비밀번호 입력 → 로그인

학생

  • 숙제·자습: 학생 선택 → 아이디 / 비밀번호(선생님이 발급) 로그인
  • 배틀만 참가: 로그인 화면의 🎮 단어 배틀 참가하기 → 코드 + 이름 입력 (로그인 불필요)
💡 항상 최신 화면업데이트하면 자동으로 최신 화면이 떠요. 혹시 옛 화면이 보이면 Ctrl+F5 한 번이면 됩니다.

2학생 등록 · 반 관리

학생관리 탭에서 학생을 만들고 반으로 묶어 관리합니다.

  1. 이름 입력, 반(예: 초등5반) 입력
  2. 아이디·비밀번호는 비워두면 자동 발급, 기존 걸 쓰려면 직접 입력
  3. 아이디 발급 → 목록에 추가됨

등록된 학생은 반별로 묶여 표시되고, 반 이름 옆에 인원수가 나옵니다. 반이 없는 학생은 “반 미지정”으로 모여요.

반 변경: 학생 카드의 ✏️를 눌러 반을 바꿔요(기존 반은 자동완성). 빈칸으로 저장하면 “반 미지정”이 됩니다.

엑셀로 한꺼번에 등록

  1. 📥 예시 엑셀 먼저 받기로 틀 파일을 내려받아요
  2. 틀 안에 이름 · 반 · 아이디 · 비밀번호를 채워요 (반·아이디·비번은 비우면 자동 발급)
  3. 📄 학생 명단 엑셀 올리기 → 미리보기 확인 → N명 등록하기
💡 틀부터 받으세요예시 엑셀을 먼저 받아 그 칸에 맞춰 입력하면 형식 오류 없이 한 번에 등록됩니다.
💡 반을 먼저반을 지정해두면, 나중에 과제·배틀을 반별로 한 번에 배정할 수 있어 편합니다.

3교재 올리기 · 보관함

학원에서 쓰는 단어책을 미리 다 올려두고(보관함), 필요할 때 꺼내 씁니다. 과제관리 → 교재 통째로 등록

업로드 방법 두 가지

버튼언제 쓰나
📗 엑셀·PDF 올리기 (빠름)한 줄에 단어 하나인 단순한 엑셀/표. 즉시 읽음.
🤖 AI로 정확히 읽기한 줄에 여러 단(Unit이 옆으로 나란히) 등 복잡한 표·PDF. 수십 초 걸리지만 정확.
  • 영어만 자동 추출 — 번호·머리글·품사(n. v.)·한글전용 줄은 알아서 걸러요. 영어=단어, 한글=뜻.
  • 단위 자동 인식 — Day / Unit / Lesson / 과 / 주차를 인식해 그 번호대로 나눔. 필요하면 단위 표기 버튼으로 바꿔요.
  • Day별 단어 수 표시 — 읽자마자 “Unit 1 · 9개” 처럼 개수가 칩으로 떠서, PDF를 다시 안 열어도 됩니다.

보관함에 저장하기

배정 대상에서 보관을 고르면 학생에게 안 보이고 📦 보관함에만 저장돼요. 요일·마감 없이 그냥 쌓아두면 됩니다.

⚠️ 스캔 PDF 주의사진처럼 스캔된 이미지 PDF는 글자 추출이 안 돼요. 엑셀로 올리거나, 텍스트형 PDF를 사용하세요.

4과제 내기(배정)

보관함 교재를 학생에게 내주는 방법. 원본은 보관함에 그대로 남아 계속 재사용할 수 있어요.

교재 전체를 한 번에

  1. 과제관리 → 📦 보관함 → 교재 선택
  2. 📤 이 교재로 과제 내기 클릭
  3. 배정 대상(전체반별개별) 선택 + 마감일 자동 배치(시작일·요일)
  4. 배정하기 → 사본이 학생에게 나감 (원본은 보관함 유지)

과제 하나씩 손보기 — 카드의 ✏️

과제 카드의 마감 … ✏️를 누르면 한 자리에서:

  • 마감일 · 녹음 횟수(1/2/3회) 변경
  • 배정 대상 전체/반별/개별/보관 변경
  • 단어 목록 수정 — 오타 고치기, 빠진 단어 추가 (한 줄에 단어 / 뜻)

교재 상세의 일괄 도구

도구기능
⏭ 뒤로 미루기특정 날짜부터 마감일을 한꺼번에 뒤로
🗓 일정 다시 짜기시작일·요일로 교재 전체 마감일 재계산
🔁 녹음 회차 한꺼번에특정 Day부터 끝까지 회차를 한 번에 변경
🧹 중복 정리실수로 두 번 올린 중복 과제 정리(제출 있는 건 보존)
교재 전체 삭제이 교재의 모든 Day 삭제
💡 자료는 안 사라져요배정은 상태만 바꾸는 것이라, 🗑나 “교재 전체 삭제”를 직접 누르지 않는 한 과제·교재는 계속 남아 재사용됩니다.

5발음 · 음가 음원 🎵

파닉스 음가나 발음 견본을 항목마다 붙여, 학생이 카드암기·녹음 화면에서 듣게 합니다. 과제 카드의 🎵 클릭.

  • 파일 업로드 — 직접 녹음한 mp3·m4a를 항목마다 올리기
  • 🔊 소리 생성 — 읽을 영어 텍스트를 적으면 자동으로 음원 생성 (녹음 없이도)

음원이 있으면 학생 화면에서 브라우저 기계음 대신 이 소리가 재생돼요. ▶로 미리듣기, 교체·삭제 가능.

6단어시험지 PDF 📝

교재의 단어로 종이 시험지를 만듭니다. 교재 상세의 📝 이 교재 단어시험지 만들기 (책 전체).

  • Day(Unit)마다 A4 한 장씩, 단어 수에 맞춰 글자 크기가 자동 조절돼요.
  • 이미 등록된 과제의 단어를 그대로 쓰므로 따로 파일 안 올려도 됩니다.
  • PDF로 다운로드 → 인쇄해서 사용.

7실시간 학습현황

학습현황 탭 — 지금 누가 무엇을 하고 있는지 한눈에. 7초마다 자동 갱신.

  • 가로: 녹음 · 카드암기 · 뜻고르기 · 스펠링 · 미니테스트
  • 세로: 학생 명단. 각 칸에 몇 시에 했는지 표시
  • 최근 5분 이내면 🟢 학습중으로 초록 강조 → 숙제반 때 진행 상황 파악
  • 학생 이름을 누르면 단어 자습 점수 상세를 볼 수 있어요

8제출 확인 · 채점

제출확인 탭 — 학생 녹음을 듣고 코멘트를 남깁니다.

  1. 반/학생 선택 → 과제 목록(Day 1부터 순서대로)
  2. 과제 열기 → 항목별 녹음 재생 · 점수(정확도/유창성/완성도) 확인
  3. 선생님 코멘트 작성 (✨ AI 코멘트로 초안 자동 생성 가능)
  4. 확인 완료로 표시 → 학생에게 코멘트가 보이고 “확인완료”로 바뀜

9단어 배틀 🎮

배틀 탭 — 실시간 4지선다 대결. 정답 맞힌 학생마다 선생님 화면에 풍선이 떠올라요.

  1. 문제 만들기: 단어 과제로(보관함 교재 여러 개 합치기) 또는 직접 만들기(문제 / 정답 입력 — 한국사 등 과목 무관)
  2. 배틀 시간(기본 1분 30초)·문제당 시간 선택 → 배틀 열기
  3. 화면의 숫자 4자리 코드를 학생에게 알려주기
  4. 학생: 로그인 화면 🎮 단어 배틀 참가하기 → 코드 + 이름
  5. 모두 모이면 배틀 시작 → 중간·최종 순위 공개
💡 찍기 방지정답 위치가 1·2·3·4번에 골고루 섞여서, 한 번호만 찍어서는 유리할 수 없어요.

10성적표

성적표 탭 — 기간을 정하면 학생별 학습 리포트를 이미지로 만듭니다.

  • 녹음 발음(종합 점수·정확도·유창성·완성도) + 단어 자습(평균·모드별 점수)까지 함께 반영
  • 일자별 추이 그래프, 과제별 기록, 더 연습할 단어, 선생님 총평
  • 이미지(PNG)로 저장 → 학부모에게 공유

11학생 화면은 이렇게 보여요

학생이 로그인하면 달력이 뜨고, 위에 두 개의 탭이 있어요.

탭내용
📅 녹음 숙제날짜를 누르면 그날 숙제 → 단어/문장을 회차만큼 녹음 제출
📚 단어 자습배정된 단어장으로 카드암기 · 뜻고르기 · 스펠링 · 미니테스트

카드 암기는 넘길 때마다 발음이 자동 재생되고(선생님 음원이 있으면 그 소리), 자습 점수는 자동 저장돼 학습현황·성적표에 반영됩니다.

?자주 묻는 것

올린 교재가 안 보여요

보관으로 올렸다면 📦 보관함 그룹에 있어요(“전체”가 아니라). 삭제된 게 아니라 위치만 다른 거예요.

과제를 냈는데 학생 화면에 안 떠요

과제 카드 ✏️에서 배정 대상이 그 학생의 반/개인으로 되어 있는지, 보관 상태가 아닌지 확인하세요. 마감일이 달력의 그 날짜에 있어야 그 날에 보입니다.

동시 접속은 몇 명까지?

숙제반 15명 정도는 무난해요. 여러 명이 동시에 녹음 채점을 누르면 채점이 잠깐 줄서서 느려질 수 있는데, 보통은 시차가 생겨 괜찮습니다.

처음 접속이 느려요

한동안 아무도 안 쓰면 서버가 잠들었다 깨어나느라 첫 접속만 수십 초 걸릴 수 있어요. 그 뒤론 빠릅니다.
